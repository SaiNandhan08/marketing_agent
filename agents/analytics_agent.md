# Analytics Agent — Performance Metrics

## Overview

Collects or simulates campaign performance metrics (open rate, click rate, unsubscribe rate, bounce rate) per persona segment after a campaign is sent.

## Agents

### MetricsCollectorAgent
Fetches metrics from HubSpot Marketing Email API if available, or generates realistic simulated metrics seeded per persona.
