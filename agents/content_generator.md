# Marketing Agent — Content Generation

## Overview

The content generation pipeline produces a research-grounded blog post and three persona-specific newsletters from a single topic input. Before any writing happens, a **ResearchAgent** gathers live context — recent articles, LinkedIn and Twitter discussions, credible sources, and active voices on the topic. This context flows into every downstream agent.

---

## Model

```
claude-opus-4-6
```

- Adaptive thinking (`thinking: {type: "adaptive"}`) on all agents
- Streaming for ResearchAgent and BlogAgent (long output)
- Prompt caching on all system prompts (`cache_control: {type: "ephemeral"}`)
- Server-side tools: `web_search_20260209`, `web_fetch_20260209`

---

## Full Pipeline Flow

```
User Input: topic
        │
        ▼
┌───────────────────┐
│   ResearchAgent   │  ← web_search + web_fetch (server-side tools)
│                   │    Gathers: articles, tweets, LinkedIn posts,
│                   │    influencers, quotes, source URLs
└────────┬──────────┘
         │  ResearchBrief
         ▼
┌───────────────────┐
│    BlogAgent      │  ← uses ResearchBrief as grounded context
│                   │    Produces: title, outline, markdown with citations
└────────┬──────────┘
         │  blog_title + blog_markdown
         ▼
┌─────────────────────────────────────────────┐
│           NewsletterAgents (× 3)            │  ← run in parallel
│  agency_owner │ ops_manager │ creative_lead │
└─────────────────────────────────────────────┘
         │
         ▼
  Artifacts saved to disk + SQLite
```

## Agent 1: ResearchAgent

**Responsibility:** Gather live, verifiable information on the topic before any content is written.

### What it answers

1. **Recency** — How recent is the conversation around this topic? Any news in the last 7–30 days?
2. **Sources** — Which credible blogs, publications, or research papers have covered this?
3. **Social pulse** — Who is actively posting on Twitter/X and LinkedIn about this right now?
4. **Influencers** — Which thought leaders, founders, or practitioners are driving this conversation?
5. **Prior coverage** — Has NovaMind or similar brands written about this before? What angle is already saturated?
6. **Unique angle** — What perspective has NOT been covered well yet?

### Tools (Claude server-side)

| Tool | Usage |
|---|---|
| `web_search_20260209` | Search for recent articles, Twitter threads, LinkedIn posts, blog coverage |
| `web_fetch_20260209` | Fetch and extract content from specific URLs found in search results |

### Search queries issued (auto-generated by agent)

```
"{topic}" site:twitter.com after:2026-01-01
"{topic}" site:linkedin.com after:2026-01-01
"{topic}" blog OR article 2026
"{topic}" thought leaders OR experts
"{topic}" agency OR "creative teams" OR "operations"
```

### Claude API pattern

```python
response = client.messages.create(
    model="claude-opus-4-6",
    max_tokens=16000,
    thinking={"type": "adaptive"},
    system=[{
        "type": "text",
        "text": RESEARCH_SYSTEM_PROMPT,
        "cache_control": {"type": "ephemeral"}
    }],
    tools=[
        {"type": "web_search_20260209", "name": "web_search"},
        {"type": "web_fetch_20260209",  "name": "web_fetch"}
    ],
    messages=[{"role": "user", "content": f"Research this topic: {topic}"}]

```

Claude autonomously issues multiple searches, fetches pages, and compiles findings. The agent loop continues until Claude returns `stop_reason: "end_turn"` with the compiled `ResearchBrief`.

**Prompt file:** `app/prompts/research.py`

## Agent 2: BlogAgent

**Responsibility:** Write a 450–600 word blog post grounded in the ResearchBrief.

The blog is not a generic AI-written post. It:
- References real sources from the ResearchBrief
- Quotes actual influencers (with attribution)
- Addresses the coverage gap identified by ResearchAgent
- Includes inline citations with source URLs

### Input
- `topic`
- `campaign_date`
- `research_brief` — full JSON output from ResearchAgent

### Output
```json
{
  "blog_title": "...",
  "blog_outline": ["...", "..."],
  "blog_markdown": "# Title\n\n...[Ann Handley](url)..."
}
```

### Claude API pattern
```python
with client.messages.stream(
    model="claude-opus-4-6",
    max_tokens=64000,
    thinking={"type": "adaptive"},
    system=[{
        "type": "text",
        "text": BLOG_SYSTEM_PROMPT,
        "cache_control": {"type": "ephemeral"}
    }],
    messages=[{
        "role": "user",
        "content": build_blog_prompt(topic, campaign_date, research_brief)
    }]
) as stream:
    final = stream.get_final_message()
```

**Prompt file:** `app/prompts/blog.py`

## Agent 3: NewsletterAgent (× 3, parallel)

**Responsibility:** Reframe the blog topic and research findings for a specific persona's pain points.

Each newsletter:
- Picks the most relevant insight from the ResearchBrief for that persona
- References one influencer quote if relevant
- Has a persona-specific subject line and CTA

### Personas

| Persona | Pain point angle | CTA style |
|---|---|---|
| `agency_owner` | Revenue, client delivery, competitive edge | "Book a demo" / "See how teams like yours..." |
| `ops_manager` | Efficiency, tool consolidation, saving hours | "Start your free trial" / "Cut X hours this week" |
| `creative_lead` | Creative freedom, reducing admin, quality | "Protect your creative time" / "See it in action" |

### Parallelism

```python
from concurrent.futures import ThreadPoolExecutor

with ThreadPoolExecutor(max_workers=3) as pool:
    newsletters = list(pool.map(
        lambda persona: newsletter_agent.run(topic, persona, blog_title, research_brief),
        ["agency_owner", "ops_manager", "creative_lead"]
    ))
```

**Prompt file:** `app/prompts/newsletter.py`

## Hooks

### Pre-research hook
- Check if a `ResearchBrief` already exists for this topic + date (avoid redundant API calls)
- Validate topic is not empty or too vague (< 3 words)

### Post-research hook
- Log `recency_score` and `is_trending` to console
- Warn if fewer than 3 credible sources were found
- Save `ResearchBrief` to `data/campaigns/{campaign_id}/research.json`

### Post-blog hook
- Save `blog.md` to `data/campaigns/{campaign_id}/blog.md`
- Log token usage + cache hit rate
- Validate blog contains at least 1 citation from ResearchBrief

### Post-newsletter hook
- Save `newsletters.json` to `data/campaigns/{campaign_id}/newsletters.json`
- Mark campaign status as `"generated"` in SQLite
- Print subject lines for all 3 personas

---

## Prompt Caching Strategy

| Prompt | Cached part | Dynamic part |
|---|---|---|
| Research system prompt | Persona profiles, search strategy instructions | Topic in user message |
| Blog system prompt | Brand voice, format rules, citation style | Topic + ResearchBrief in user message |
| Newsletter system prompt | All 3 persona profiles, format rules | Persona + blog title + brief in user message |

All system prompts exceed the 4,096 token minimum threshold once persona context and examples are included.
